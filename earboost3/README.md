# EarBoost 3
Experimental Android 17 Bluetooth Ear (3) LoudnessEnhancer audio-session-0 app.
Audio effects on global session 0 are deprecated and may be ignored by Nothing OS firmware.
The slider requests up to +50% **amplitude** (+3.52 dB), not 50% perceptual loudness.
It cannot bypass physical limits, hearing protection, Bluetooth chip firmware or DSP restrictions.
No root, no privileged system app, no Nothing X changes.
Built as an automatically signed Android debug APK for sideloading.
